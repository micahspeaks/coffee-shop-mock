# Aster & Ember Coffee

An original, static editorial coffee website built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Extract the ZIP file.
2. Create a new GitHub repository.
3. Upload everything **inside** the `aster-ember-coffee` folder to the repository root.
4. Keep the `assets` folder and its three images together.
5. Open **Settings → Pages**.
6. Choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then save.

No installation or build step is needed.

## Repository structure

```
index.html
styles.css
script.js
README.md
assets/
  editorial-coffee.jpg
  matcha-cloud.jpg
  tiramisu-cold-brew.jpg
```
